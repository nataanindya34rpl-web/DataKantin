Jelaskan  mengapa berbeda. : Jika menggunakan NumPy array, harga * 0.9 akan mengalikan setiap harga dengan 0.9. Sedangkan pada list Python, [5000,7000,3000] * 0.9 menghasilkan error karena list tidak mendukung perkalian dengan bilangan desimal.
